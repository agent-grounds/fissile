# E2E-101-an-add-at-the-hard-limit-names-the-hard-entry-as-a-persons-decision: add's refusal at the limit frames the hard route the same way

`exception add --severity soft --max 8` under a hard limit of 8 is refused and
names the hard-severity call carrying that ceiling as the other route
(§FS-005-exception-add.4). Off a terminal that call is refused in turn, so the
refusal says first that a hard entry is a person's decision recorded at a
terminal, and names splitting the file beside it.

The run's standard input is closed, as an agent's is. Nothing is written.
