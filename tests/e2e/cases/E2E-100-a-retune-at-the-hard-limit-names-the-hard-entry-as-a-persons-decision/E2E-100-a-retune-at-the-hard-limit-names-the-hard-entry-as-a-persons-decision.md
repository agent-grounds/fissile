# E2E-100-a-retune-at-the-hard-limit-names-the-hard-entry-as-a-persons-decision: the hard route is offered as a person's decision, beside splitting the file

A soft ceiling at the hard limit silences nothing, so `retune --max 8` under a
hard limit of 8 is refused and offers the hard-severity `exception add` as the
other route (§FS-008-exception-retune.4). That command is refused off a terminal
(§FS-005-exception-add.4), and an agent's shell has none. So the refusal says,
before the command, that a hard entry is a person's decision recorded at a
terminal, and names splitting the file as the route the caller takes itself.

The run's standard input is closed, as an agent's is. Nothing is written.
