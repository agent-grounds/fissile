# E2E-102-an-empty-range-names-splitting-and-a-person-at-a-terminal: the empty-range line names both routes left

When a soft entry's file measures one unit under the hard limit, no soft
ceiling grants headroom, and the loose line names the hard registry instead
(§FS-004-check-audit.2, case 2). Accepting the file there is a person's decision
recorded at a terminal, and the line is printed by a hook or CI whose reader may
have none, so it names splitting the file beside it. The run is a report and
exits `0`.
